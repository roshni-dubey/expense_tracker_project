# Expense Tracker

A command-line expense tracking application developed using Python to help users record daily expenses and monitor their spending.

## Features
- Add and record daily expenses
- View total expenses
- Simple command-line interface
- Beginner-friendly implementation

## Technologies Used
- Python

## How to Run
1. Install Python 3.
2. Download `expense tracker.PY` from this repository.
3. Open a terminal in the file's directory.
4. Run:

```bash
python "expense tracker.PY"
```

## Purpose
This project demonstrates foundational Python programming concepts and basic expense management functionality.
